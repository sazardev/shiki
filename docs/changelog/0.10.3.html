shiki v0.10.3

Released 2026-10-30.

Share: X Bluesky Reddit Hacker News WhatsApp Telegram Email

Fixed

  • macOS: startup no longer opens the Rename dialog with the terminal's OSC 10/11 reply in the input. Darwin's poll(2) reports POLLNVAL for /dev/tty (and other tty/pty fds), so the startup color query returned before reading either answer; crossterm then parsed the late bytes as Alt+] plus stray characters — with NOTES focused, the r in rgb: triggered Rename. The readiness wait now uses select(2) on macOS (shiki-tui/src/term_colors.rs), the same workaround crossterm's filedescriptor dependency uses, and the "auto" selection band resolves correctly there instead of always falling back to darkgray. (#114)
